# 无界译 · Wujie Translate

无界译是独立的 Obsidian 插件。在笔记里选中文字后点「翻译所选文字」，也可以点侧边栏图标或用「查词和翻译」命令手动输入。翻译可切换目标语言和复制译文。英汉查询从国内无界服务读取词典，牛津高阶排在第一，朗文当代高级英汉双解排在第二。

在测试库的 `.obsidian/plugins/` 下放入构建生成的 `wujie-translate` 文件夹，在 Obsidian 社区插件中启用 **Wujie Translate**。打开无界译设置，填写已有的国内无界服务授权码。授权由当前库的 Obsidian SecretStorage 管理，插件可以独立启用。牛津和朗文由后台维护，无界译没有词库导入入口。

发起请求时，插件将当前所选或输入的文字和目标语言发送到国内无界服务。线上词典或翻译会按服务配置使用上游供应商。插件不会自动发送笔记或保存翻译历史。网络断开时仍可关闭面板，恢复网络后点「重试」。

`npm ci` 安装构建依赖，`npm test` 运行专项测试，`npm run build` 生成可安装文件和 SHA-256 清单。Obsidian 最低版本为 1.12.7。
